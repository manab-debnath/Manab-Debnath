### 🚀 About Me

- 🔭 **Current Focus:** Architecting robust backend services, microservices, and real-time distributed applications.
- ⚡ **Real-Time & Concurrency:** Designing collaborative tools, streaming endpoints, and event-driven systems using **WebSockets**, **Socket.io**, and **gRPC**.
- 🛠️ **Monorepos & Performance:** Structuring scalable workspaces with **Turborepo**, deploying serverless functions, and leveraging fast modern runtimes like **Bun** and **Node.js**.
- 🗄️ **Data & Infrastructure:** Deep hands-on experience with **PostgreSQL**, **Redis** caching, **Prisma ORM**, containerized with **Docker** & **Kubernetes**.
- 💬 **Ask me about:** TypeScript, NestJS, Hono, Cloudflare Workers, microservice architectures, and database optimizations.
- ⚡ **Fun Fact:** I can debug a race condition faster than deciding what to eat! 🍕
